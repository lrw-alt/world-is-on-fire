# Code Review

## Comprehensive Checklist
1. **Functional Correctness**: Verify all user acceptance criteria and edge cases.
2. **Security & Data Invariants**: Check authentication checks, database query scoping, and secret protection.
3. **Performance**: Avoid unnecessary re-renders, optimize database queries, minimize bundle footprint.
4. **Clean Code & Idioms**: Clear naming, early returns, no dead code, full type annotations.
