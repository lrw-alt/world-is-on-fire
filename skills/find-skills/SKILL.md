# find-skills

Use this skill to look up and install relevant skills from skill.sh whenever you need extra capabilities, debugging playbooks, architectural guidelines, or specialized tools.

## Guidelines
- Always inform the user before installing any new skill.
- Query skill.sh for skills matching the current domain (e.g. ui-styling, refactor, audit, performance).
- Install verified skills into `.grok/skills/` or `skills/` directory.
