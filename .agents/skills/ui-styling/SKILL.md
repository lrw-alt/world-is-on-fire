# UI Styling & Component Guidelines

## Tailwind & Component Standards
- Direct utility classes with responsive prefixes (`sm:`, `md:`, `lg:`).
- Proper spacing rhythm: 4px step scale (`p-4`, `p-6`, `gap-4`).
- Accessible touch targets: Minimum 44px on interactive controls.
- Color balance: Pass WCAG AA standards (4.5:1 contrast ratio for body text).
