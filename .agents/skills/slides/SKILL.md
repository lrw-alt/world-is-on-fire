# Slides & Presentation Design

## Architecture & Layouts
- **Aspect Ratio**: Standard 16:9 widescreen canvas with responsive scale transforms.
- **Card Patterns**: Key point callouts, comparison splits, stat highlights with descriptive subtitles.
- **Visual Contrast**: Dark luxury themes or clean crisp light themes with high readability.
- **Keyboard Navigation**: Left/Right arrow keys, Space/Back navigation, fullscreen toggle.
