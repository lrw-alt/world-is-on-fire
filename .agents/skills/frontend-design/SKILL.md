# Frontend Design

## Craftsmanship Guidelines
- **Modern Typography Scales**: Step ratios >= 1.25, line heights 1.5-1.7, line widths 65-75ch.
- **Rhythmic Spacing**: Group related elements tightly; use generous padding between major sections.
- **Micro-Animations**: Smooth entry transitions with `motion/react`, hover elevation shifts, active click tactile feedback.
