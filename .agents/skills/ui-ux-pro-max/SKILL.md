# UI/UX Pro Max

## Professional UI/UX Standards
- **Optical Balance & Precision**: Never rely on generic AI slop templates. Every spacing and typography decision has mathematical purpose.
- **Micro-Interactions**: Smooth state transitions with `motion/react` (fade, slide, stagger).
- **Accessible State Handling**: Render loading skeletons, empty states, error boundaries, and optimistic updates for every interactive surface.
- **Stack-Specific Craft**: Optimized patterns for React, Tailwind CSS, Lucide icons, and Radix primitives.
