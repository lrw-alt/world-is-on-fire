# Banner Design Skill

Use this skill when designing promotional banners, hero graphics, display ads, or social headers.

## Key Principles
- **Visual Hierarchy**: Primary headline (high contrast), supporting subcopy, distinct CTA button, and balanced negative space.
- **Responsive Layouts**: Design for common aspect ratios (16:9, 1:1, 4:3, 3:1 leaderboard, 1:2 skyscraper).
- **Brand Consistency**: Adhere to tokenized color palettes, typography pairs, and clean asset framing.
- **Performance & Asset Weight**: Optimize vector assets (SVG) and raster images for fast load times.
