# Create README

## README Structure
1. **Project Title & Overview**: Clear 1-2 sentence description of what the project does.
2. **Key Features**: High-level functional highlights with bullet points.
3. **Tech Stack**: Framework, language, database, and libraries used.
4. **Getting Started**: Quick install and run instructions (`npm install`, `npm run dev`).
5. **Project Structure**: Overview of key directories and files.
