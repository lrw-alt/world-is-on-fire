# Design Skill

## Visual & Interaction Framework
- **Layout & Composition**: Asymmetric balance, strict modular grids, clear typographic hierarchy.
- **Micro-Interactions**: Subtle, purposeful animations (150ms-250ms) using cubic-bezier easings.
- **Color Psychology**: Context-driven color assignments ensuring semantic clarity and legibility.
- **Presentations & Slides**: Clear slide layouts, scannable bullet cards, high-contrast charts, and visual narrative pacing.
